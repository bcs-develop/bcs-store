# BCS Store for BMW MGU

BCS Store is a planned BCS-branded distribution of the MGU Store project originally developed by Robert Nisipeanu (IterioDev).

**Status: publishing preparation only.** No app packages or live update catalog have been released from this repository yet.

## Publishing checklist

- Include complete corresponding source code and modifications for GPL-covered Store components, with upstream copyright and license notices.
- Audit each bundled third-party app/runtime package for its own license and redistribution terms.
- Remove secrets, private SSH keys, customer data and license-signing material from all published assets.
- Build Store packages with BCS GitHub catalog/release URLs and preserve original developer credit.
- Verify package hashes and downloads; test on a backed-up ID7/ID8 bench unit before enabling customer updates.

Do not treat this repository as a functioning app feed until a verified catalog and release assets are published.
